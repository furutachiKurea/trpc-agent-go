概念边界

自动 CR Agent 不是普通 scanner。 issue 明确讨论 Skill、沙箱、Permission/Filter、Telemetry、SQLite/持久化。一个 scanner 只覆盖 finding 产生的一部分背景。

finding 和 warning 不是同一层。 severity、confidence、source、rule_id、dedup、needs_human_review 是结构化审查结果的背景词。

deterministic rule-only 是验收背景。 它说明该系统的部分行为应能在无真实模型 API key 时被验证；课程只解释这个概念，不给出实现步骤。
